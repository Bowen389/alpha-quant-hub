## 二、每日自动盘后候选系统（GitHub Actions）

本仓库内置两套解耦定时工作流：
- **主流程** [`.github/workflows/daily.yml`](./.github/workflows/daily.yml)：每个交易日北京时间 `17:00 / 18:00 / 21:00` 及次日 `08:30` 自动拉取最新主板全市场日线与核心 ETF 日线，生成 **`reports/YYYY-MM-DD.md`** 与 **`reports/latest.md`** 并提交回主分支；
- **兜底监控** [`.github/workflows/postclose-watchdog.yml`](./.github/workflows/postclose-watchdog.yml)：独立定时巡检，若 GitHub Actions 偶发跳过主流程则自动补触发。

每日报告统一覆盖：
1. **大盘与短线情绪门控仪表盘**（沪深 300 vs MA20/MA30、主板等权 vs MA20、中证 1000 vs MA20、全主板涨停/跌停家数、近 3 日昨涨停溢价，直接给出 `STRICT_MA30 / SOFT_R11 / LOOSE_R9` 仓位指令）；
2. **#1 / #3 `Evo-S1 V2` & `V2-Cap` 次日 09:25 候选清单**（含 `Evo-P2`、`Evo-BF`、`Evo-FB` 精确次日开盘触发价区间）；
3. **#5 / #6 `U1-Pure6Fac-Top1` & `ZF2` 全池 6 因子排名清单**（次日 09:25 谁落入触发区间且排名最靠前即为唯一第 1 名）；
4. **#4 `AlphaFlow-Switch-22` 纯权益 ETF 轮动今日收盘调仓信号**（国内主攻 Top 2 / 海外 4 核替补 / 100% 现金）；
5. **#15 `Champion-V2 Top800` 大盘稳健 5 因子 Top 15 观察池**。

## 三、本地运行方式

```bash
# 1. 云端接口拉取最新交易日并生成报告（GitHub Actions 默认模式）
python scan_daily.py

# 2. 手动指定历史交易日
python scan_daily.py --date 2026-11-25

# 3. 使用本机通达信 Parquet 缓存离线秒出报告（零网络依赖）
python scan_daily.py --local-tdx "C:\Users\HBWve\.gemini\antigravity\scratch\tdx_quant\cache"
```
